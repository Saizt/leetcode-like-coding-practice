# LeetCode-Like Coding Practice

This repository contains my implementations of common algorithmic and data-structure interview problems.

The goal is to practice clean, interview-ready Python implementations with:

- clear problem descriptions
- core algorithmic ideas
- time and space complexity analysis
- testing and debugging with `assert` and `unittest`
- OPT: adapting existing code to progressively changing requirements

- Dynamic Programming
- Class-style data structure design
